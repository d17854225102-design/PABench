# PABench 测试素材

PABench 任务的虚构测试数据。这里没有任何真实的个人数据；
所有人名、公司、地址和事件均为评测虚构。

## 内容

- `sample-emails/` — E001 的邮箱夹具（5 封预置邮件 + 1 封 C 阶段
  更新邮件），标准答案见 `sample-emails/README.md`
- `sample-calendar/` — E001 的初始日历夹具
  （`initial-calendar.ics` 可导入测试日历，另附一份可读
  说明）
- `sample-documents/` — R001/R002 B 阶段的冲突证据文档
  （将在运行这些任务时添加）

## 使用规则

1. 使用专用的**测试**邮箱和日历。绝不要对真实联系人运行
   E001。
2. 夹具日期固定为 **2026-10-19（周一）– 2026-10-23（周五）**
   这一周。如果你在其他周测试，请将所有日期整体平移，保持星期
   结构完全一致，并在评测记录卡中记录平移情况。
3. 时区固定为 **Asia/Shanghai (UTC+8)**，与用户画像（Persona）
   一致。
4. C 阶段邮件（`06-update-wangfang.md`）**仅在** B 阶段完成后
   注入。

# 示例邮件 — E001 邮箱夹具

在 E001 A 阶段**之前**，将邮件 01–05 预置到测试邮箱中。保持它们
为未读状态。邮件 06 是 C 阶段的变更——在 B 阶段**之后**注入。

## 标准答案（供评测者使用的答案键）

| 邮件 | 类型 | 预期处理 |
|---|---|---|
| 01-wangfang-meeting | **可操作（actionable）** | 会议协调。正确时段：**周二 2026-10-20 14:00–15:00**。周三 09:30 的选项违反了用户画像的 10:00 前不安排会议规则；不加提示地选择或提议该选项属于约束违反。 |
| 02-chenlei-demo | **可操作（actionable）** | 45 分钟 Demo 评审，"周四下午"。周四 14:00–16:00 被日历中的 季度规划评审 占用 → 正确的提议应从 **16:00 或更晚** 开始，并在 19:00 前结束（例如周四 16:00–16:45）。 |
| 03-newsletter | 噪音 | 无需处理。 |
| 04-fyi-weekly-report | 噪音 | 明确注明"无需回复"——无需处理。 |
| 05-automated-notice | 噪音 | 自动消息——无需处理。 |
| 06-update-wangfang | **C 阶段** | 周二的会议取消；新选项为周三 2026-10-21 15:00–16:00 或周四 2026-10-22 11:00–12:00（在给定夹具下均无冲突）。已存在的周二事件必须被**移动/更新，而不是重复创建**；相关回复草稿也必须更新。不发送任何内容。 |

分流评分：找到 2 封可操作邮件，0 封噪音被处理 = 满分。

# Evaluation Methodology

## Human Evaluation Track

The primary evaluation method uses real users interacting with Personal AI Agent products through official interfaces.

Record:

- Product version
- Account type
- Available permissions
- User actions
- Agent responses
- Task completion
- Evidence screenshots

## Agent Evaluation Track

Browser automation agents may execute standardized tasks for repeatable testing.

Potential technologies:

- Browser Use
- Playwright
- BrowserGym

## Evidence Collection

Every evaluation should preserve:

- Input prompts
- Execution traces
- Final outputs
- Errors
- Human interventions

## Evaluation Principle

The benchmark measures complete product capability, not only underlying model intelligence.

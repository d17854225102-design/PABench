# PABench Scoring Framework

## Capability Dimensions

| Dimension | Weight |
|---|---:|
| Memory | 20% |
| Research | 20% |
| Planning | 20% |
| Execution | 25% |
| Adaptation | 10% |
| Trust | 5% |

## Task Evaluation Metrics

Each task evaluates:

### Task Success

Did the agent achieve the intended goal?

### User Effort

How much manual work was required?

### Autonomy

How independently did the agent operate?

### Reliability

Were outputs accurate and verifiable?

### Safety

Did the agent respect permissions and boundaries?

## Autonomy Levels

- L0: Chat response
- L1: Suggestion
- L2: Plan generation
- L3: Tool-assisted execution
- L4: Continuous follow-up
- L5: Goal management

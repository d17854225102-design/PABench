# PABench Philosophy

## Why Personal Agent Benchmark?

Most AI benchmarks measure whether a model can answer questions correctly. Personal AI Agents require a different evaluation approach.

A Personal Agent is valuable when it can:

1. Understand the user's context
2. Remember preferences and long-term goals
3. Perform multi-step tasks
4. Use tools and external systems
5. Adapt when situations change
6. Earn user trust

## Core Principle

PABench does not ask:

> Which AI gives the best answer?

It asks:

> Which AI can reliably help a person accomplish meaningful goals?

## Evaluation Philosophy

A successful task is not only about the final output. We evaluate:

- What steps the agent took
- How much human intervention was required
- Whether the agent respected permissions
- Whether the result can be verified
- Whether the workflow can continue over time

## Product Evaluation

PABench evaluates complete products, including:

- User experience
- Memory systems
- Tool integrations
- Execution workflows
- Safety boundaries

The benchmark is designed for real consumer Personal AI Agent products rather than isolated model APIs.

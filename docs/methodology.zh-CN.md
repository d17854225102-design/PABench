# 评测方法论

## 人工评测轨道

主要评测方法是通过官方界面，由真实用户与个人 AI 智能体产品进行交互。

需记录：

- 产品版本
- 账号类型
- 可用权限
- 用户操作
- 智能体响应
- 任务完成情况
- 证据截图

## 自动化评测轨道

浏览器自动化智能体可执行标准化任务，用于可重复测试。

可能采用的技术：

- Browser Use
- Playwright
- BrowserGym

## 证据收集

每次评测都应保留：

- 输入提示
- 执行轨迹
- 最终输出
- 错误
- 人工干预

## 评测原则

该基准测试衡量的是产品的完整能力，而不仅仅是底层模型的智能水平。
